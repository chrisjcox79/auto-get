SCP Reference Help

23 Nov 2020 04:54

I've seen a number of SCPs myself, but not enough. So at the moment there are 2 ideas that might have some potential.

1) An object that can observe past histories

2) A D-class that does not die

.

+block

–block

With the first, I originally concepted this object being a magnifying glass, however I did note after conception that there's a magnifying glass entry on some knock-off SCP website that refers to themselves as scp classic? Store, cache, preserve? Even if it isn't canon I think my concept can be mixed up a bit more than taking that specific form.

The key element is that this object would be able to reference an edit log for anything that is seen through it. You know, how on some of these posts you can see an edit history? That's the idea, but it could be all contents ever written on a whiteboard. Or in a notebook. But even deeper, say in a long held manuscript; like the Quran, or the Bible. Maybe even ████████ material? Naturally the key to this concept would be in the story surrounding it, but I want to know if this idea exists in the scp lore in anyway. I'm sure people have used time travel in their creation, but this specific trait just might be limiting enough to push a tale.

I do comprehend, being able to see redacted material is a dangerous idea, being that author makes that information unavailable to guide the mystery of it. But if used correctly, it has good potential to revive an old topic. Obviously requires a test of scrutiny.

.

The second concept is a lesser one in which I simply considered: What if there was a D-class that always survived their testing? If we apply this nature to a soldier or a doctor? Sure, there is some possibility, but D-class always gets the worst of it. So again, I want to know if there's any D-class that are SCPs.

This idea has less wiggle room being, at the moment, it's just an entity with writers shield. But there might be some fun to be had with this concept. P.S. I am not thinking of a character trait like Marvel's Darwin, where his body just adapts to any situation. Not my intent what-so-ever. Nor do I wish to pursue some  trait akin to Domino. What would the D-class be I dunno, but I don't want to start concepting if there's already another similar D-class on the list.

.

If you can help I'd dearly appreciate it.
