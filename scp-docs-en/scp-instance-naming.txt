SCP instance naming

27 Dec 2020 00:54

I often see SCP-XXXX-1 and it doesn't seem entirely clear as to what this is used for, I see it used to designate objects that come from or exist in an SCP such as SCP-3008-1 but if I recall correctly I believe I remember sing it as an event or a title describing somethings anomalous properties. so what exactly is this for? additionally I'm wondering if something like SCP-XXXX-1-1 would be acceptable or if it should just be referred to as SCP-XXXX-2. I have no specific ideas that would entail using the SCP-XXXX-1-1 designation but I'd like to know if such a thing could be used and in which circumstances.

Re: SCP instance naming

27 Dec 2020 01:11

so what exactly is this for?
附加记录：    

Basically any sort of specific thing that is related to a primary anomaly, but distinct enough to make more sense to mention specifically. So if the Foundation was containing an anomalous field and there was an anomalous rabbit that only shows up in that field, the field would be SCP-XXXX and the rabbit would be SCP-XXXX-1. That helps prevent confusion/strange sentences where it would make sense to refer to only one thing at a time (for example,  makes sense for the rabbit, not the field).

additionally I'm wondering if something like SCP-XXXX-1-1 would be acceptable or if it should just be referred to as SCP-XXXX-2.
附加记录：    

It depends on what relationship that something has to SCP-XXXX-1. You would use an offshoot that has an existing designation offshoot number if you're referring to a specific part of that previously designated thing. To use the previous example, if the rabbit carried a good luck charm that had its own anomalous properties, that might be SCP-XXXX-1-1, though I think most authors would use SCP-XXXX-1-A or SCP-XXXX-1a or the like.

So basically:

SCP-XXXX: main anomaly/main collection of anomalies the Foundation is containing
SCP-XXXX-1: part of/a component of SCP-XXXX
SCP-XXXX-1-A: part of/a component of SCP-XXXX-1
and so on.
