SCP Conversion Project

03 Apr 2020 16:00

For the past around 5 months I've been working on creating a completely open-source view-only re-implementation of the SCP Wiki, and it is now to the point of being near-complete. It is hosted here: https://scp.karagory.com/

It looks and acts like the normal SCP Wiki for the most part, ignoring a few bugs, and I think it could be very useful to Project Foundation. Most of the work went into creating the  graphs, and it allows access to the intermediate representation of the pages, which should be useful to somebody out there. More information about how it works is available on the website itself, I made a custom front page with more information on there.

I hope this helps with the long term development of Project Foundation.
